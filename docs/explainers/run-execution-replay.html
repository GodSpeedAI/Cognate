Why Replay Solves The Distributed Execution Trap

Traditional workflows freeze threads or store complex execution state graphs in memory. When the host crashes or an unhandled exception occurs, the in-flight state is orphaned.

In Cognate, execution state is simply a pure function over the stream: State = fold(Events). When executeOnce wakes up, it re-reads run-<id> and calls the agent function from line 1. When ctx.invoke is reached, it sees stepId: "invoke:0" already in the map, skips the remote API call, and immediately returns the recorded output. External models and payment APIs are called exactly once, while the code retains ordinary synchronous readability.

Verification Evidence: Proven by packages/runtime-bun/test/run-execution.test.ts (CAS race recovery) and packages/runtime-bun/test/shutdown-recovery.test.ts.
