# proto / src / gen — generated protobuf TypeScript bindings

## Overview

Generated TypeScript bindings for the canonical `proto/` sources, emitted into `src/gen` by `buf generate` with the pinned local `protoc-gen-es` plugin `[packages/proto/scripts/generate.ts:1]`. Every file carries a `// @generated by protoc-gen-es v2.15.0 with parameter "target=ts"` header naming the source `.proto` file `[cognate/v1/event_pb.ts:1]`. The directory currently holds ten `cognate/v1/*_pb.ts` files covering identity, artifact, capability, continuation, event, execution, component, cognitive, trace, and runtime `[packages/proto/buf.gen.yaml:inputs]`.

## Interface

- `file_cognate_v1_event` — `GenFile` descriptor for `cognate/v1/event.proto` `[cognate/v1/event_pb.ts:file_cognate_v1_event]`
- `Event` — generated message type for the canonical durable event envelope `[cognate/v1/event_pb.ts:Event]`
- `Erasure` — generated message type for payload-erasure metadata `[cognate/v1/event_pb.ts:Erasure]`
- `EventSchema` — `GenMessage<Event>` descriptor for the envelope message `[cognate/v1/event_pb.ts:EventSchema]`
- `RuntimeService` — `GenService` describing the runtime's RPC methods `[cognate/v1/runtime_pb.ts:RuntimeService]`
- `GenMessage` / `GenFile` imports from `@bufbuild/protobuf/codegenv2` — the runtime the emission targets `[cognate/v1/event_pb.ts:5]`
- Re-export surface: `packages/proto/src/index.ts` is the only hand-written file and re-exports each generated module `[packages/proto/src/index.ts:1]`

## Invariants

- These files are generated; `packages/proto/AGENTS.md` states `src/gen/**` is never hand-edited, that changes go to `proto/` followed by re-running `bun scripts/generate.ts` `[packages/proto/AGENTS.md:1]`
- `packages/proto/package.json` describes the output as generated bindings whose files are never edited by hand `[packages/proto/package.json:description]`
- Output directory is `src/gen` unless a first CLI argument overrides it `[packages/proto/scripts/generate.ts:outDir]`
- Inputs come from the directory `../../proto` and the plugin binary is the pinned local `node_modules/.bin/protoc-gen-es` `[packages/proto/buf.gen.yaml:plugins]`
- Generation is reproducible: two runs into temp directories produce byte-identical digests that must equal the committed `packages/proto/src/gen` `[packages/proto/test/codegen.test.ts:27]`
- The generated `RuntimeService` exposes only `unary` and `server_streaming` methods `[packages/proto/test/codegen.test.ts:43]`

## Side Effects

- The generator spawns `node_modules/.bin/buf generate --template buf.gen.yaml -o <outDir>` in the package directory `[packages/proto/scripts/generate.ts:Bun.spawn]`
- Generation writes `.ts` files into the output directory, overwriting existing bindings `[packages/proto/scripts/generate.ts:outDir]`
