Architectural Invariant
Semantics constrain execution. Events preserve truth. Cognition discovers relevance. Observations record execution. Representations remain replaceable.
In Cognate, canonical_history != derived_state. Two paths run through the same durable event log and never merge: the Authority Path (which decides what is true or admitted) and the Projection Path (which folds events into read models, UI state, and vector indices).
