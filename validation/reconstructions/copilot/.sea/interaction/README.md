# CopilotKit Reconstruction Interaction Model

This directory is the canonical interaction-model location for the reconstruction. T1–T4 now add
documented-reference journeys; C1 remote capability discovery and live AG-UI delivery remain
explicitly unresolved instead of being hidden in reconstruction glue.

Files:

- `interaction-model.sea`: SEA representation.
- `canonical-journey-catalog.md`: settlement definitions and final canonicality conclusion.
- `source-translation-map.md`: evidence-to-model trace.
- `assumptions-and-unknowns.md`: evidence boundaries and architectural-gap status.
- `handoff.md`: allowed downstream Cognate projection.
- `validation/`: reproducible validation outputs and limitations.
