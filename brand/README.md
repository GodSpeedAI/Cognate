# Cognate brand assets

The mark is a **socket C**: a capability cartridge seated in the C of Cognate. The C is the
application and the cartridge is a capability plugged into it, the same unit the landing page's
exploded view uses. Cognate is a GodSpeed AI product, so the mark follows the GodSpeed visual language
(`godspeed-growth/brand/visual/visual-language.md`): Prussian Blue carries identity and muted gold marks the
sanctioned capability. The wordmark is Josefin Sans Regular (+10 tracking), converted to outlines.

| File | Use |
|---|---|
| `cognate-mark.svg` | Mark, light backgrounds (Prussian Blue `#003153`, muted gold `#D7A84A`) |
| `cognate-mark-reversed.svg` | Mark, dark backgrounds (white `#FFFFFF`, gold `#D7A84A`) |
| `cognate-mark-mono.svg` | One colour; inherits `currentColor` |
| `cognate-mark-512.png` | Raster mark for avatars and app icons |
| `cognate-lockup.svg` / `cognate-lockup-reversed.svg` | Mark and wordmark |

Clear space: at least the cartridge's height around the mark (1.5x on square canvases; 12 to 16% padding for avatars). Don't recolour the cartridge
apart from the mono version, and don't set the wordmark in another face. The mark has not been
trademark-screened (U8 in `actualize/`).
