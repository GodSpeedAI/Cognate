The Ports-and-Adapters Law of Cognate

In many agent frameworks, database types leak into business logic, or React components depend directly on concrete transport protocols.

Cognate prevents this structurally: every layer has an abstract contract package (*-api or events) and a swappable implementation adapter. The just check and just gate CG-ARC-001 recipes enforce an acyclic graph with zero illegal cross-boundary imports across all 45 packages.
