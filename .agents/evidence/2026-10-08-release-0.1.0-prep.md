## Limits (publication blocked, not attempted-failed)

- npm publication of `@cognate/*` is blocked by namespace ownership: an npm **user** named `cognate` exists (0 packages) and only it (or a future `cognate` org it converts into) can publish the scope. Publishing as the currently logged-in `sprime01` account returns 404 (masked 403) — verified once with `cognate-kernel-api-0.1.0.tgz`. The scope was NOT claimed by any accidental publish.
- Because packages do not exist on npm yet, per-package trusted publishers cannot be configured (npm requires the package to exist); the publish job therefore stays gated on the `NPM_TRUSTED_PUBLISHING_READY` repository variable instead of failing red on main.
- No provenance attestations will be generated: npm does not support them from private repositories (docs, verbatim). The workflow does not claim them.
- Pre-existing (documented, not new): copilot `J-E-controlled-rendering` timeout on main; deepseek J-B concurrent-load flake.
