# UCB1 adaptive ranker (AK-008) — 2026-09-25

**Decision:** operator chose UCB1 to replace SONA (ADR-0005 addendum); DEBT-008 closed.

**Change:** `createOutcomeRanker` (`packages/capabilities/src/selector.ts`) scores
`successes/total + sqrt(2 ln N / total)` with `N` summed over the eligible providers;
untried providers score `Number.MAX_VALUE` (finite, accepted by the selector). The
outcome projection is unchanged.

**Contract first:** `packages/capabilities/test/adaptive-ranker.test.ts` was written
before the change and failed on the greedy ranker (2 of 6: untried-first, exact UCB1
scores / exploration of an under-observed provider).

**Proofs (AC-008-01):**
- ranks only the supplied eligible set, even when an excluded provider has the best record;
- untried providers first, ties by provider id;
- exact UCB1 scores; re-tries a provider a greedy ranker would abandon;
- closed loop over 200 rounds converges on the better provider (>150 plays) while
  still exploring the other (>3 plays);
- projection reset + rebuild restores identical scores;
- an unavailable projection falls back to provider-id order with the failure recorded.

**Commands:** `bun test ./packages/capabilities ./tests/properties/containment.property.test.ts` — 14 pass, 0 fail.
`just verify` / `just gates` results are recorded in the status revision for this change.
