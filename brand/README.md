# Cognate brand assets

The mark is a **socket C**: a capability cartridge seated in the C of Cognate. The C is the
application and the cartridge is a capability plugged into it, the same unit the landing page's
exploded view uses. The wordmark is Newsreader (wght 560, opsz 72), converted to outlines.

| File | Use |
|---|---|
| `cognate-mark.svg` | Mark, light backgrounds (ink `#161b22`, signal `#ba4300`) |
| `cognate-mark-reversed.svg` | Mark, dark backgrounds (`#ebe7e0`, `#ee8545`) |
| `cognate-mark-mono.svg` | One colour; inherits `currentColor` |
| `cognate-mark-512.png` | Raster mark for avatars and app icons |
| `cognate-lockup.svg` / `cognate-lockup-reversed.svg` | Mark and wordmark |

Keep clear space of at least the cartridge's height around the mark. Don't recolour the cartridge
apart from the mono version, and don't set the wordmark in another face. The mark has not been
trademark-screened (U8 in `actualize/`).
