## EGM.md (root)

- Count claim understated: the Overview says "Roughly fifty `@godspeedai/cognate-*` packages are hoisted into root `devDependencies` as `workspace:*`". Root `devDependencies` (`package.json:37-103`) contains 45 `@godspeedai/` entries, of which 44 match the stated `@godspeedai/cognate-*` pattern (the 45th is the bare umbrella `@godspeedai/cognate`). The underlying workspace set is 43 packages plus 2 profiles (`ls -d packages/*/` = 43, `ls -d profiles/*/` = 2). The stated order of magnitude is ~50; the actual count is 44.
- `actualize` is described as "a closed Product Actualizer run ledger with per-lens artifacts and evidence, carrying no TypeScript of its own". `actualize/evidence/fidelity-qa/measure/measure.ts` is a TypeScript source file inside the tree (it imports `chromium` from `landing/node_modules/playwright/index.mjs` and writes measurement output), so the tree does carry TypeScript of its own.
- `examples` is described as "one `index.ts` per directory composing real workspace packages and throwing on an unexpected result". `examples/` holds 16 directories but only 15 `index.ts` files; `examples/refund-desk/` has no `index.ts` (its entry is `src/refund-desk.ts`, run via `"dev": "bun src/server.ts"` in `examples/refund-desk/package.json`).
- Status-history invariant overstated: the Global Invariants section says "the last entry must be reflected verbatim in the human view". `scripts/check-substrate.ts:49` compares only two fields — `**Status revision:** <revision>` and `**Summary:** <summary>` — via `human.includes(...)`. The remaining snapshot fields (`stage`, `verified`, `limits`, `next`, `evidence`, `spec`, `ledger`, `recorded_at`) are never compared against `.agents/CURRENT_STATUS.md`, so a human view matching on revision and summary alone passes.

## Method and limits

Mechanical verification performed: every symbol, option field, default, error class, and file path named by the 12 contracts was located with targeted `grep`/`sed`/`ls` against the specific file and line range, never with a repo-wide recursive find. Counts were computed directly: `git rev-parse --short HEAD` (the only git command run) = `2020aba`; 16 `rpc` declarations in `runtime.proto`, matching that contract's "16 unary/server-streaming RPCs" claim exactly (15 unary, 1 server-streaming); 5 `workspaces` globs in root `package.json` (`packages/*`, `profiles/*`, `tests/e2e`, and two `validation/reconstructions/` trees), matching its "five `workspaces` globs" claim; 45 `@godspeedai/` devDependency entries, 44 with the `cognate-` prefix versus the root contract's "roughly fifty" (reported above); 43 package directories, each with an `EGM.md`, a `src/` tree, an `exports` map, `engines.bun` `>=1.4.0`, and `license` `Apache-2.0`; 45 entries in `.release-please-manifest.json` (43 packages + 2 profiles) all at `0.8.0`; 10 `.proto` files, all `proto3` in `package cognate.v1`; 10 generated `_pb.ts` files under `packages/proto/src/gen`.

Every `## Verification` command in the 12 contracts was resolved to its target. All exist: `packages/runtime-bun/test/`, `packages/events/test/`, `packages/kernel-cordis/test/` (which imports `contractSuite` from `@godspeedai/cognate-kernel-api/conformance`), `packages/proto/test/codegen.test.ts`, `packages/store-postgres/test/`, `packages/provider-wire/test/wire.test.ts`, `tests/proof-routing.test.ts`, `tests/release-publication.test.mjs`, and `tests/integration/cli-create.test.ts`. Every script filename and flag cited by `scripts/EGM.md` was found in the named script: `gate.ts` accepts `--all` and `--implemented` and takes `.tmp/gates.lock`; `db.ts` implements `up`, `down`, `status`, `migrate`, `backup`, `restore`, `vacuum`; `setup-pg0.ts` has `DIGESTS` and the `no recorded sha256 for` failure; `prepare-npm-package.mjs` rewrites only the three `workspace:` ranges on non-dev sections; `plan-sdk-release.mjs` fails on `Linked SDK versions diverge`; `check-readmes.mjs` accumulates `problems` and calls `process.exit(1)`.

Limits of this pass: (1) No test suite was executed, so the verification commands are confirmed to *target existing files* but their current pass/fail state is unverified. (2) `file:line` citations were evaluated semantically — a citation resolving to the correct construct a few lines from the stated number was not counted as drift, since the claim it supports is true. (3) Behavioral claims that require execution to falsify (that `commit` is atomic, that positions are gap-free under concurrency, that a checkpoint is never ahead of its rows) were checked only against the implementing code, not against runtime behavior. (4) Some side-effect claims depend on the host rather than the repo: "local PostgreSQL instances persist under `~/.pg0/instances`" appears only as prose in `justfile:75` and was not observed on disk. (5) The 12 audited contracts' claims about *other* documents were followed only one hop (e.g. the existence of `packages/events/src/EGM.md`); the content of those other contracts was not audited except where listed. (6) This pass does not distinguish stale-but-harmless from materially wrong; all six findings are reported at equal weight. (7) `packages/provider-wire/EGM.md` was verified against a single 56-line `src/index.ts`, so "no drift" there is a strong result; the contracts with the largest claim surface (root, store-postgres, scripts) carry correspondingly more residual risk.

## Remediation applied after the audit

Five of the seven reported findings were corrected in the contracts before commit. One reported finding was withdrawn, and one further defect that the audit did not catch was found and fixed by a repo-wide link sweep.

| Finding | Disposition | Change |
|---|---|---|
| Root: "roughly fifty `@godspeedai/cognate-*` packages" vs 44 | **Withdrawn as a finding; wording tightened** | The count in the report is wrong: root `devDependencies` holds 45 `@godspeedai/` entries (43 `packages/*` + 2 `profiles/*`), so the workspace set is 45, not 44. "Roughly fifty" was an accurate order-of-magnitude statement, not drift. It was replaced with the exact figure `45` to remove the ambiguity that invited the miscount. |
| Root: `actualize` "carrying no TypeScript of its own" | **Fixed** | Now names `actualize/evidence/fidelity-qa/measure/measure.ts` as the one TypeScript file in that tree, with a direct citation. |
| Root: "one `index.ts` per directory" for `examples` | **Fixed** | Now states 15 single-file `index.ts` demonstrations plus the multi-file `refund-desk` app under `src/`. |
| Root: "last entry must be reflected verbatim in the human view" | **Fixed** | Now states what `check-substrate.ts:49` actually enforces: `**Status revision:** N` and `**Summary:** …` must both appear in `.agents/CURRENT_STATUS.md`. |
| `packages/EGM.md`: 18 packages listed as unlinked | **Fixed** | All 18 now have relative links to their child contracts. |
| `packages/events/EGM.md`: "No child `EGM.md` exists under this package" | **Fixed** | Now links `./src/EGM.md`. |
| `packages/ui-astryx/EGM.md`: `src/` marked "no EGM.md present" | **Fixed (not in original audit)** | Found by the follow-up sweep; `src/` now links `./src/EGM.md`. |
| 11 further blueprints with an existing child `src/EGM.md` left unlinked, plus `proto/EGM.md` (`cognate/`) and `templates/EGM.md` (`starter/`) | **Fixed (not in original audit)** | A repo-wide sweep now reports **0** children with an `EGM.md` that their parent blueprint fails to link, and **0** broken relative links across all 173 contract files. |

Two findings share one root cause and are worth recording as a process lesson: contracts written concurrently cannot see each other's output, so any "child contract does not exist" statement is only true at the instant it is written. A post-pass link sweep is mandatory for parallel bootstraps; the drift checklist should include it. The corrected claim class is now absent from the tree.
